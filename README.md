# Pharmacy Pill Counter · 알약 카운터

모바일 우선, 기기 내 OpenCV.js 분석 → 번호·윤곽 검수 → 수동 수정 → 최종 확인 웹앱입니다. 서버나 계정 없이 작동합니다.

## 사용법
1. 무광 단색 배경에 알약이 닿지 않도록 펼치고 목표 수량을 선택합니다.
2. 사진을 불러오거나 후면 카메라로 촬영합니다. 최대 35MB, 분석 해상도는 긴 변 1280px입니다.
3. 모든 번호와 윤곽을 대조합니다. 확대 후 스크롤로 이동하고, `누락 추가` / `오검출 삭제`를 선택해 알약 중심을 터치합니다.
4. 위치 없이 수량만 바꿀 때는 +/−를 사용합니다. Undo/Redo 지원. 재분석 시 기존 수정은 초기화됩니다.
5. 직접 검수 확인란을 체크한 후 확인 완료를 누릅니다. 저장은 선택 사항입니다.

카메라는 **HTTPS 또는 localhost**, 카메라 권한이 필요합니다. Android Chrome / Samsung Internet의 후면 카메라를 우선 요청합니다. 사용 불가 시 사진 불러오기 또는 기본 카메라 촬영을 이용하세요. 실제 Android 하드웨어 검증 여부는 `TESTING.md`를 참조하세요.

## 개인정보·저장
- 사진은 브라우저 Web Worker에서 분석됩니다. 사진 업로드 API, 분석 서버, 광고·추적 도구는 없습니다.
- 앱 파일과 OpenCV(약 10MB)는 같은 사이트에서 내려받습니다. 호스팅 제공자는 일반적인 접속 정보를 처리할 수 있습니다.
- 기본값: 기록 저장 OFF, 사진 영구저장 OFF. 체크한 경우에만 IndexedDB에 저장합니다. 사진을 선택하면 원본 파일(포함된 메타데이터 포함)을 이 기기에 저장합니다. 환자 정보가 찍히지 않게 촬영하세요.
- JSON 내보내기는 사용자가 요청할 때 다운로드하며 사진 자체는 포함하지 않습니다. 사진 포함 여부는 `imageSaved`에 기록됩니다.
- `기록 삭제`는 해당 앱의 기록·사진을 삭제합니다. 브라우저 사이트 데이터 삭제로도 제거할 수 있습니다. 공유 기기에서는 저장에 주의하세요.
- PWA 서비스 워커는 앱 파일만 캐시합니다. 최초 정상 로드 이후 오프라인 분석을 지원합니다. 저장 사진을 서비스 워커에 캐시하지 않습니다.

## 검출 한계
임상 검증이나 실제 약국 사진에 대한 정확도 검증을 마친 제품이 아닙니다. 자동 수량만으로 조제를 확정하지 마세요. 단색 배경과 충분한 간격을 전제로, 테두리 배경색 추정 → 색 거리 → Otsu 임계값 → 형태학 연산 → 외곽 윤곽 필터링을 수행합니다.

서로 닿거나 겹친 알약은 하나로 계산될 수 있습니다. 그림자·반사·무늬·배경과 유사한 색·작은 파편은 오검출/누락을 만들 수 있습니다. 가장자리 물체는 제외하며 경고합니다. 알약 종류나 용량을 식별하지 않습니다. 품질 수치는 단순 진단값이며 보정된 신뢰도가 아닙니다. `confidence`는 임의 숫자 대신 null입니다.

## 로컬 실행·구조
Node.js 18 이상에서 `npm start`, 브라우저에서 `http://127.0.0.1:4173`. 별도 설치/빌드가 필요 없습니다. `npm test`로 핵심 상태·통계 테스트를 실행합니다.

- `src/app.js`: 카메라, 이미지 검수, UI
- `src/detector.js`: 검출기 비동기 어댑터; `analyze(ImageData, parameters)` 계약
- `src/detector-worker.js`: OpenCV 검출. 결과는 `objects`, `detector`, `quality`, `warnings`, `processingTimeMs`
- `src/history.js`: 수정 이력과 FP/FN 계산
- `src/storage.js`: IndexedDB 저장과 정확도 집계
- `vendor/opencv.js`: OpenCV 4.9.0 공식 배포본, Apache-2.0 (`vendor/LICENSE-OpenCV.txt`)

OpenCV: [공식 JS 문서](https://docs.opencv.org/4.9.0/d0/d84/tutorial_js_usage.html), [배포 파일](https://docs.opencv.org/4.9.0/opencv.js).

## 최소 데이터 루프
`기록 · 테스트`에서 개발·테스트 모드를 열거나 URL에 `?test=1`을 붙입니다. 별도로 센 정답을 입력할 수 있고, 비워두면 사용자가 확인한 최종 수량이 정답 후보입니다. 같은 사진의 재확인은 같은 sampleId를 갱신해 중복 집계를 막습니다.

저장: 자동 객체 좌표·윤곽, 최종 객체, 추가(FN)/삭제(FP), 수량 보정, 자동/최종/정답 수량, 알고리즘·파라미터, 품질 수치, 처리 시간. FP/FN은 사용자의 위치 수정으로부터 산출한 후보값입니다. 수량 보정이 있거나 별도 정답과 최종 수량이 다르면 객체 수준 Ground Truth는 미확정입니다.

Exact Count Accuracy는 **자동 수량 = 확인 정답 수량**인 기록 비율입니다. 연습 버튼의 합성 이미지와 분석 실패 기록은 정확도 집계에서 제외합니다. 합성 이미지 테스트는 실사진 정확도를 입증하지 않습니다.

AI 모델은 검출기 어댑터를 교체해 연결할 수 있습니다. 학습/파라미터 자동 최적화/대규모 벤치마크는 구현하지 않았습니다. 사용자 검수 데이터가 충분히 쌓인 뒤 별도로 검증해야 합니다.
